About the course

The course starts with the language features introduced in C++11 and later, then moves through smart pointers, ownership, and concurrency. Each lecture connects the language rules to the design decisions behind reliable C++ code.

Course topics

  • Templates Generic programming and compile-time abstraction.
  • Modern language features Practical use of C++11, C++14, and C++17.
  • Smart pointers Ownership, lifetime, and memory management.
  • Concurrency Threads, synchronization, and parallel execution.
